# Flows

Part of the [Piper design standards](../README.md).

### First load (desktop)
1. Black (soot) → Line Rat draws (1.2 s) → tail becomes pipe → `Piper` + *Follow the rats.* (shown once per session; skip on any key/click; never under reduced motion).
2. UI clusters fade in (220 ms), map reports fade in, then rings on the top 10.
3. Right panel shows **This week's 10**. Focus starts on ⌘K.

### Inspect a site (the demo path)
⌘K → "which places have reports after closure?" → Ask answers, chips list 3 sites →
click Normandy St chip → map flies (with `mapPadding`, foundations/space-layout.md), site selected, rings draw,
Dossier opens with headline *Monitored eleven times.* → toggle "Show the Tune" →
brass notes drift from the vacant lot → Approve on "Issue a violation" → work
order rises, seal stamps → Print.

### Findings
Tab Findings → scroll feed → "Show on map" on *Trash out early → reports 3 weeks later* → lenses set, timeline marks the lag.

### Field (phone, Bone)
Open → map + peek "This week's 10" → tap row → sheet to 50% with Dossier header
and stat row → swipe/tap to 92% → Approve (48 h, full width) → work order full
screen.
