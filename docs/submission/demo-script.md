# Demo Script (under 3 minutes)

> One take, no dead air. Show the task finishing. Narrate the evidence and the
> human decision point — those are scored.

- 0:00–0:20 — The problem, in one real sentence. Who, what task, why it's hard.
- 0:20–1:30 — The flow, live: intake → evidence (point at the citation) →
  review screen (the human decision point) → ready-to-use output.
- 1:30–2:10 — Accessibility: tab through it with the keyboard; mention the
  screen-reader labels and contrast.
- 2:10–2:45 — Kiro: show `.kiro/specs` and one hook firing, in ~20 seconds.
- 2:45–3:00 — What's real vs. demo-scoped. End on the finished task.

## Recording checklist
- [ ] Clean dataset / no real PII on screen.
- [ ] Browser zoom readable; cursor visible.
- [ ] Audio levels checked.
- [ ] Final file is public and under 3:00.
