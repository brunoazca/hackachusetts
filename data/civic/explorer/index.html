Gotchas before you join

  • Zip codes lose their leading 0 in spreadsheets. Zero-pad to 5 characters.
  • Most live API calls return only ~100 rows. Demo on the committed data.csv; use fetch.py to refresh.
  • Snapshots differ in time window: 311 is recent weeks, permits/violations since 2024, Numina is 2020-2021, Bluebikes is Nov 2024 only. Say so on screen.
  • Counts are not rates. Divide crashes by bike volume, 311 cases by population.
  • Scorecard earnings are not causal, and PrivacySuppressed is not zero.
  • Vision Zero is crash location, not where people live. Avoid framing it as "dangerous neighborhoods".
  • Check each source license before republishing a slice (every dataset README repeats this).
