# Civic starter kits

Each folder is one dataset: data.csv, README.md, fetch.py, and fetch.js.
Open data.csv in a spreadsheet, or run fetch.py for a fresh response from the direct URL.

- boston-311: Boston 311 service requests
- mbta-alerts: MBTA service alerts
- mbta-routes: MBTA subway routes
- mbta-stations: MBTA rapid transit stations
- ej: MassGIS environmental justice block groups
- fema: OpenFEMA disaster declarations, Massachusetts
- permits: Boston approved building permits
- neighborhoods: Boston neighborhood estimates, 2025
- violations: Boston building and property violations
- scorecard: College Scorecard, Massachusetts
- onet: O*NET occupations
- ipeds: IPEDS institutional directory, Massachusetts
- openalex-works: OpenAlex works at the nine campuses, 2024
- colleges: MassGIS colleges and universities
- bluebikes: Bluebikes station-to-station counts, November 2024
- vision-zero: Boston Vision Zero crash records
- cambridge-crashes: Cambridge police crash records
- cambridge-bikes: Cambridge citywide bicycle counts
- eco-totem: Cambridge Broadway bicycle counter
- fresh-pond: Cambridge Fresh Pond usership
- somerville-counts: Somerville bicycle and pedestrian counts
- numina: Boston Numina street sensors
